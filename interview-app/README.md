# 안다윤의 면접실

검역지원요원 채용 자료를 바탕으로 만든 브라우저 면접 연습 앱입니다.

- 30개 질문을 분야별로 섞어서 출제합니다. 한 회차 안에서 중복되지 않습니다.
- 브라우저 음성 합성 및 한국어 음성 인식을 사용합니다. 음성 인식 미지원 또는 실패 시 직접 입력할 수 있습니다.
- 연습 모드는 즉시 평가·모범답안·꼬리질문을 제공하며, 실전 모드는 종료 후 공개합니다.
- 모범답안은 실제 제공된 경력 범위에서 2문장으로 작성했습니다.
- 점수는 질문별 핵심 표현 및 문장 구성에 따른 **규칙 기반** 평가입니다. 생성형 AI 의미 분석이 아니며 부정문·유사표현을 잘못 판단할 수 있습니다.
- 답변과 점수는 이 기기의 localStorage에 최대 20회 저장합니다. 원본 음성은 보관하지 않습니다. 브라우저 음성 인식 서비스로 음성이 전송될 수 있습니다.

## 실행

배포된 HTTPS 사이트에서 사용하세요. 로컬 실행: 프로젝트 폴더에서 `python -m http.server 8765 --directory dist` 실행 후 http://localhost:8765 접속. 지원되는 Chrome 또는 Edge에서 마이크 권한을 허용하세요. `index.html` 직접 열기는 음성 기능을 보장하지 않습니다.
