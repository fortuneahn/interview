# 남성 음성

기본 목소리는 Microsoft 한국어 남성 `ko-KR-InJoonNeural`로 생성한 MP3입니다.
질문 30개, 꼬리질문 30개, 모범답안 30개와 미리 듣기 1개를 포함합니다.
브라우저에 남성 음성이 설치되지 않아도 같은 파일을 재생합니다.

`dist/male-audio.js`는 문장과 MP3 경로를 연결합니다. 파일명에 문장 해시를
포함하므로 질문을 수정한 후 다시 생성하면 새 파일을 사용합니다.
문장마다 필요한 MP3만 불러오며, 사용자 답변은 음성 생성 서비스로 보내지 않습니다.
재생 실패 시 오류를 표시하고 직접 입력을 허용합니다.

재생성: Python에 `edge-tts`를 설치한 뒤 `python generate-male-audio.py`를 실행합니다.
현재 음성은 edge-tts 7.3.1로 생성했습니다. 생성 시 질문 은행의 텍스트를
Microsoft 음성 서비스로 전송하며, 배포된 앱에서는 이 서비스에 접속하지 않습니다.
`node test-male-audio.cjs`로 파일과 재생 흐름을 검증합니다.
